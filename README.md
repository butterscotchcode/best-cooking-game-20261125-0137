# Dapur Kilat

A 2D canvas cooking game: run a kitchen through a 150-second shift — order board, ingredient counter, chopping board, wok, plates, and serving table. Played with keyboard and mouse in a desktop browser, from static files with no network request.

Open `game/index.html` in a desktop browser to play.
